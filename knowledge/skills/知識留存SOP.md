# 📝 知識留存 SOP

> 建立: 2026-05-20 | 作者: Lucas

## 目的
確保團隊學到的經驗教訓和關鍵知識不會流失，任何成員都能隨時取用。

## 觸發時機
以下情況應啟動知識留存程序：
1. **Lesson Learnt** — 犯錯、踩坑、debug 成功後
2. **技能升級** — 學到新工具、新技巧、更有效率的做法
3. **決策記錄** — 做了重要技術或架構決策
4. **外部知識** — 從網路、文件、對話中學到的有用知識

## 寫入流程

### Step 1: 辨識是否需要留存
- 這件事以後還會遇到嗎？ → 是 → 留存
- 這件事對其他成員有用嗎？ → 是 → 留存
- 這只是一個一次性資訊？ → 放 archive 或直接跳過

### Step 2: 選擇分類
```
knowledge/
├── lessons/    → 失誤教訓：[流程]、[技術]、[溝通]、[決策]
├── skills/     → 可重複執行的 SOP / 技能
├── templates/  → 任務模板、報告模板
└── archive/    → 已過時但保留參考價值的
```

### Step 3: 建立檔案
- 檔名格式：`YYYY-MM-DD_簡短標題.md`
- 使用對應目錄的 TEMPLATE.md
- 填寫：日期、作者、分類標籤、內容

### Step 4: 同步到 Discord #知識庫（✅ 必要步驟）
- **必須**寫入 Discord 頻道 #知識庫（ID: 1506448287979405502）
- 格式：`📚 新知識：[分類] 標題 — 一句話摘要`
- 包含完整內容或摘要連結
- 這是知識真正流通的關鍵環節，不可跳過

## 誰可以留存
- **Lucas** — 任何技術/流程/架構相關
- **八雲** — 使用者反饋、溝通模式、營運相關
- 建議每月審視一次 archive 目錄

## 定期維護
- 每月 1 日：審視本月新增知識
- 將過時或不再適用的移入 archive/
