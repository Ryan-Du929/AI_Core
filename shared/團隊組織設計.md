## 溝通協定

```
Ryan → [Discord 大廳] → 八雲（結構化）
                           ↓
八雲 → [shared/queue/] → Lucas（任務）
                           ↓
Lucas → [shared/results/] → 八雲（結果）
                           ↓
八雲 → [Discord 大廳] → Ryan（報告）

直接對話：Ryan ↔ [ryan-private / lucas-workspace] ↔ Lucas
```

### 規則
1. 八雲：只傳遞結構化任務，不做分析或修改
2. Lucas：只回報結果，不做即時討論（除非在私人頻道）
3. 結果回報統一用 shared/results/ 格式
4. 狀態同步：每日至少一次進度更新到 #lucas-workspace

---

## 任務分派規則
1. Ryan 的指示 → 八雲結構化 → 寫入 queue/
2. Lucas polling queue/ → 拆解為子任務 → 執行
3. 完成後結果寫入 results/ → 八雲轉達
4. 一次只派一個任務（避免淹沒）
