支撐技術

兩條核心研究主線

主線 A｜CPFEM constitutive parameter identification研究焦點已由單純「加速 fitting」推進到 multi-objective calibration、Bayesian optimization、parameter identifiability、uncertainty 與 transferability。
主線 B｜跨晶格應力 / 滑移傳遞預測研究脈絡可由「跨材料泛化 → 局部應力場 surrogate → grain-level slip transmission → heterophase / dissimilar-lattice interface transfer」逐步閱讀。

目前最值得追的研究缺口

不同 crystal structures + slip-system geometry + orientation/interface descriptors → transferable stress / slip-transfer prediction
  • 同材料 grain-to-grain slip transmission：2026 已有 GNN。
  • BCC/FCC、HCP/BCC 異質界面物理：2025–2026 已有實驗、CP、PFDD 與 interface law。
  • 尚未成熟的是把兩者整合成跨晶格、physics-aware、可轉移的 AI 模型。

技術時間軸：2024–2026 的研究演進

2024｜證明 AI 能進入 crystal plasticity

  • ML 協助辨識 active slip systems，涵蓋 FCC/BCC/HCP。
  • Temporal GNN 開始把 grain interaction / topology 納入 polycrystal response。

2025｜從單點加速走向 transfer / interface physics

  • ML 反算 CP parameters、Bayesian inference 開始成熟。
  • Transfer learning 用於 polycrystal full-field strain evolution。
  • HCP/BCC interface、通用 interface plasticity law 被更系統化。

2026｜開始碰真正難的 generalization / transmission

  • Multi-modal CPFEM calibration、non-uniqueness benchmarking。
  • CNN / Transformer 做 local stress / full-field surrogate。
  • GNN 直接預測 slip transmission pathway。
  • BCC/FCC 實驗 + CP 直接觀察 blocking / transfer / reflection。

主線 A｜CPFEM parameter identification 的演進

1

快速反算：用 ML / surrogate 降低反覆 CPFEM 搜尋成本。

2

提高約束：不只 stress–strain，再加入 EBSD grain rotation / full-field data。

3

真正瓶頸：parameter non-uniqueness、uncertainty、loading-path transferability。

4

未解問題：few-data + uncertainty-aware + cross-crystal-structure calibration。

主線 B｜跨晶格 stress / slip transfer 的演進

1

固定材料 surrogate：microstructure → stress / strain field。

2

grain interaction：GNN 學 grain-to-grain slip transmission。

3

異質界面 physics：BCC/FCC、HCP/BCC 已知 transfer / blocking / reflection 與界面控制因素。

4

未解問題：以 lattice / slip / interface descriptors 建立可跨 crystal structures 轉移的 physics-aware AI。

Living review

保留 topic、year、method、crystal structure、venue 等欄位；新增文獻時可直接併入既有分類與篩選，而非重做整份頁面。
